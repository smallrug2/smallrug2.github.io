# smallrug2 — personal site

Live at **https://smallrug2.github.io/** (GitHub Pages).

Connie — trans witch, Elder Futhark rune writer, white-hat hacker and builder.
Bio, a full Elder Futhark dictionary, rune of the hour, a rune converter, a rune
cast, code samples in Python / C++ / Java / HTML / CSS, projects, and links.

## Files

- `index.html` — the whole page
- `styles.css` — purple witchy theme
- `script.js` — rune dictionary, hours, converter, cast, code tabs
- `code/` — the rune converter in Python, C++, and Java
- `assets/` — hero banner + witch avatar art

## Security & logs

- Static site only: no backend, no database, no third-party scripts, no
  trackers, no visitor logging. Page content is built with textContent only —
  nothing typed into the converter ever becomes page HTML.
- Served over HTTPS (Enforce HTTPS is on in Pages settings).
- Visitor counts and referrers: GitHub's private Insights > Traffic tab
  (owner-only, no IP addresses). Changes to the site: the repo's commit
  history is the log — every edit leaves a commit.
